# 后续路线

## 当前版本

- FastAPI 后端。
- Web 演示页面。
- ResNet18 肺炎二分类推理。
- Grad-CAM 热力图。
- TF-IDF RAG 健康咨询。
- 医学网页抓取到 TXT 的脚本。

## 下一阶段建议

1. RAG 升级
   - 收集中文可信医学科普、指南、药品说明书摘要。
   - 把 TF-IDF 检索替换或叠加为向量检索，例如 bge-small-zh、m3e、text2vec。
   - 给回答增加“引用来源编号”和“不能回答时拒答”策略。

2. 影像模型升级
   - 加入混淆矩阵、AUROC、Sensitivity、Specificity。
   - 对比 ResNet18、DenseNet121、EfficientNet。
   - 多标签扩展到肺炎、肺不张、胸腔积液、心影增大等胸片异常。

3. Agent 编排
   - 通过意图识别自动选择“影像分析”“健康咨询”“紧急就医建议”工具。
   - 保存会话历史，但避免保存个人敏感健康信息。

4. 毕设展示
   - 加入实验结果表。
   - 加入系统架构图。
   - 加入病例示例，但注意去标识化和隐私。
