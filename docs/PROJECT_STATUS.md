# 项目状态

## 是否基本完成

当前版本可以认为是“可演示 MVP”：

- 可以本地一键启动。
- 可以进行日常健康咨询。
- 可以使用 RAG 检索知识库。
- 可以上传胸片并使用 CNN 辅助筛查。
- 可以显示 Grad-CAM 热力图。
- 可以查看系统状态。

但它还不是成熟医疗产品。成熟版本至少还需要：

- 接入并验证 Qwen 微调模型。
- 用真实测试集评估 CNN，并公开指标。
- 增加更高质量的医学知识来源。
- 做更严格的安全评测。
- 完成云服务器部署。

## 是否需要算力云

本地可以运行：

- Web demo。
- TF-IDF RAG。
- 单张胸片推理。
- 小规模测试。

建议使用算力云 GPU：

- 加载 Qwen 7B 或更大模型。
- LoRA adapter 推理。
- CNN 重训练。
- 批量胸片评估。
- 构建 embedding 向量库。

## 下一步建议

1. 把项目拷贝或 clone 到算力云。
2. 上传 CNN 权重和 Qwen 权重到数据盘。
3. 配置 `.env`。
4. 用真实问答测试 Qwen 生成质量。
5. 用真实胸片测试集跑 `scripts/evaluate_cnn.py`。
6. 把实验结果写入 README。
